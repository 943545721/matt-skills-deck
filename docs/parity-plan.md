## 判定口径（与 DSH 一致，改了口径就是 bug）

- `ready`（可接）= 未关闭 + 无认领 + 没有仍打开的阻塞者。
- `blocked`（阻塞）= 存在至少一个仍打开的阻塞者（assignee 占用单独算 `claimed`，不算 blocked）。
- `closed` = 已关闭；PR 的 `merged` 也算收尾。
- 地图票排序优先于普通票；显式排序只改次级键。
- 列表是「最近 N 条窗口」的派生视图：KPI 与计数都必须标明窗口，不能假装是全仓统计。
